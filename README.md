# branch-name

Консольний TUI-генератор назв git-гілок із назви задачі (кирилиця або латиниця) та її ID.

## Встановлення

```sh
go build -o branch-name .
# або глобально:
go install .

# збірка для Windows (з будь-якої ОС)
GOOS=windows GOARCH=amd64 go build -o branch-name.exe .
```

## Використання

```sh
branch-name                                   # інтерактивно
branch-name -id SHOP-15 Виправити помилку в кошику
branch-name "PROJ-123 Додати темну тему"      # ID буде вилучено з назви автоматично
```

Варіанти оновлюються під час введення. Перший варіант (★) має тип, визначений
за ключовими словами: `bugfix` (помилка, виправити, fix, bug…), `hotfix` (терміново, urgent…),
`refactor`, `chore`, а якщо нічого не знайдено — `feature`.

### AI-варіанти (OpenRouter)

Для довгих назв (від 5 слів або від 31 символу після транслітерації) програма просить
безкоштовну LLM на OpenRouter запропонувати короткі англійські назви, наприклад
`feature/55287-automate-report-generation`. Короткі назви генеруються локально, без запитів;
`ctrl+r` (або `r` у списку) примусово запитує AI для будь-якої назви.

Ключ і моделі задаються прямо в програмі: `ctrl+s` (або `s` у списку) відкриває
екран налаштувань. Ключ створюється на <https://openrouter.ai/keys>. Налаштування зберігаються
у файл (доступний лише власнику, права 0600):

| ОС      | Шлях                                                   |
|---------|--------------------------------------------------------|
| Windows | `%AppData%\branch-name\config.env`                     |
| macOS   | `~/Library/Application Support/branch-name/config.env` |
| Linux   | `~/.config/branch-name/config.env`                     |

Пріоритет: прапорець `-model` > файл налаштувань > змінні `OPENROUTER_API_KEY` / `OPENROUTER_MODEL`.

- Моделі за замовчуванням (пробуються по черзі): `openrouter/free`, `google/gemma-4-31b-it:free`,
  `nvidia/nemotron-3.5-lightning:free`.
- `OPENROUTER_URL` перевизначає адресу API (проксі або сумісний сервер).
- `-no-ai` вимикає AI повністю.
- Відповіді кешуються за назвою протягом сесії, тож зміна ID не витрачає ліміт.
  Безкоштовний ліміт OpenRouter — близько 50 запитів на день.

### Клавіші

| Клавіша            | Дія                                        |
|--------------------|--------------------------------------------|
| `tab` / `enter`    | наступне поле                              |
| `↑↓` (або `jk`)    | вибір варіанта                             |
| `enter` (у списку) | скопіювати й вийти                         |
| `c` / `ctrl+y`     | скопіювати без виходу                      |
| `1`–`9`            | швидко скопіювати варіант за номером       |
| `g` / `ctrl+g`     | копіювати як `git checkout -b <гілка>`     |
| `r` / `ctrl+r`     | запитати AI (навіть для короткої назви)    |
| `s` / `ctrl+s`     | налаштування (API-ключ, моделі)            |
| `ctrl+u`           | очистити поля                              |
| `esc` / `q`        | вихід                                      |

### Транслітерація

Українська — спрощена читабельна схема (`я→ya`, `ю→yu`, `є→ye`, `ї→yi`, `х→kh`, `щ→shch`),
апострофи прибираються. Якщо в тексті є `ы/э/ё/ъ` і немає `і/ї/є/ґ`, застосовуються
російські правила (`и→i`, `г→g`). Текстова частина обрізається до 50 символів по межі слова.
